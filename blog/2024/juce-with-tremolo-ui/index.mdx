## モチベーション

まず、このライブラリを作り始めた経緯をお話しします。  

プラグイン等のオーディオ・アプリケーションのUIは、既存の汎用的なUIライブラリではカバー出来ない部分がありました。代表的なもので言えば、Rotary Knob (回転ノブ)や、鍵盤などです。

また、既存のライブラリによくある Slider などでも、対数的な表示 (skew) を実装するのが大変だったりしました。

そこで現在開発しているのが、**tremolo-ui** です

https://github.com/m1m0zzz/tremolo-ui

tremolo-ui では以下のことを目標としています。

- 使いやすさと拡張性  
  → ヘッドレスUIライク・特殊なUIイベントのためのコンポーネント等
- モバイルサポート  
  → クロスプラットフォームであるJUCEと共に使用することを考慮し、モバイルでも単一のコードで動くこと

### テーマの CSS を用意する

tremolo-ui は CSS を同梱していません。コンポーネントは構造と操作だけを受け持ち、見た目は利用側が `className` で与えます。

ドキュメントの [Styling](https://tremolo-ui.mimoz.dev/docs/tutorials/styling/) のページに、デモで使っているテーマが CSS Modules で公開されているので、`Knob.module.css` と `Slider.module.css` を `webview/src/theme` にコピーして使います。

### JUCE コンポーネントの実装

Juceのバックエンドと通信するための処理が必要で、またそれを再利用可能にするために、`webview/src/components` というディレクトリを作りそこに、JUCEのライブラリでラップしたコンポーネントを作成していきます。


```tsx title="webview/src/components/JuceKnob.tsx"
import { useEffect, useState } from "react";
import { Knob } from "@tremolo-ui/react";
import { getSliderState } from "juce-framework-frontend-mirror";

import knobTheme from "../theme/Knob.module.css";

interface Props {
  identifier: string;
}

export function JuceKnob({
  identifier
}: Props) {
  const sliderState = getSliderState(identifier);
  const [value, setValue] = useState(sliderState.getNormalisedValue());

  const handleChange = (newNormalisedValue: number) => {
    console.log(newNormalisedValue)
    sliderState.setNormalisedValue(newNormalisedValue);
  };

  useEffect(() => {
    const updateWebViewValue = () => {
      setValue(sliderState.getNormalisedValue());
    };

    const valueListenerId =
      sliderState.valueChangedEvent.addListener(updateWebViewValue);

    return () => {
      sliderState.valueChangedEvent.removeListener(valueListenerId);
    };
  }, [sliderState]);

  return (
    <Knob.Root
      className={knobTheme.root}
      aria-label={identifier}
      min={0}
      max={1}
      step={0.001}
      value={value}
      onChange={handleChange}
      startValue={0.5}
      wheel={['normalized', 0.1]}
      keyboard={['normalized', 0.01]}
    >
      <Knob.SVGRoot>
        <Knob.ActiveLine className={knobTheme.activeLine} />
        <Knob.InactiveLine className={knobTheme.inactiveLine} />
        <Knob.Thumb
          className={knobTheme.thumb}
          classes={{ line: knobTheme.thumbLine }}
        />
      </Knob.SVGRoot>
    </Knob.Root>
  );
};
```

- `Knob.Root` の中に、描画する部品（`Knob.SVGRoot`・`Knob.ActiveLine`・`Knob.InactiveLine`・`Knob.Thumb`）を並べます。並べたものだけが描画されます。
- JUCE とは 0〜1 の正規化した値でやりとりするので、`wheel`（マウスホイール）と `keyboard`（矢印キー）の変化量は `'normalized'` で指定しています。
- デフォルトでは左下が回転の開始位置ですが、`startValue` で変えられます。パンのように中央から左右に振るノブでは `0.5` にします。ダブルクリックでもこの値に戻ります。


```tsx title="webview/src/components/JuceSlider.tsx"
import { useEffect, useState } from "react";
import { Slider } from "@tremolo-ui/react";
import { getSliderState } from "juce-framework-frontend-mirror";

import sliderTheme from "../theme/Slider.module.css";

interface Props {
  identifier: string;
  vertical?: boolean;
}

export function JuceSlider({
  identifier,
  vertical = true,
}: Props) {
  const sliderState = getSliderState(identifier);
  const [value, setValue] = useState<number>(sliderState.getNormalisedValue());

  const handleChange = (newNormalisedValue: number) => {
    sliderState.setNormalisedValue(newNormalisedValue);
  };

  useEffect(() => {
    const updateWebViewValue = () => {
      setValue(sliderState.getNormalisedValue());
    };

    const valueListenerId =
      sliderState.valueChangedEvent.addListener(updateWebViewValue);

    return () => {
      sliderState.valueChangedEvent.removeListener(valueListenerId);
    };
  }, [sliderState]);

  return (
    <Slider.Root
      className={sliderTheme.root}
      min={0}
      max={1}
      step={0.001}
      value={value}
      onChange={handleChange}
      orientation={vertical ? 'vertical' : 'horizontal'}
      wheel={['normalized', 0.1]}
      keyboard={['normalized', 0.01]}
      style={{ flex: '1 1 auto' }}
    >
      <Slider.Track
        className={sliderTheme.track}
        style={vertical ? { '--length': '100%' } : undefined}
      >
        <Slider.Thumb className={sliderTheme.thumb} aria-label={identifier} />
      </Slider.Track>
    </Slider.Root>
  );
};
```

Slider も同じく、`Slider.Root` の中に `Slider.Track` と `Slider.Thumb` を置いて組み立てます。

- `orientation` で縦向きにできます。縦向きのときは、トラックの長さ（`--length`）を `100%` にして、空いている高さいっぱいに伸ばしています。
- 部品ごとに `className` や `style` を渡せるので、トラックやつまみの見た目は自由に変えられます。

参照: [Slider | tremolo-ui](https://tremolo-ui.mimoz.dev/docs/components/Slider/)
